# 营养目标 Nutrition Targets

依据《中国居民膳食营养素参考摄入量（2023版）》与《中国居民膳食指南（2022）》。

## 能量计算

- 基础代谢（Mifflin-St Jeor）：男 = 10×体重kg + 6.25×身高cm − 5×年龄 + 5；女 = … − 161。
- 总能量 = 基础代谢 × 活动系数 × 人群模型 `kcal_factor` + 人群模型 `kcal_delta`。
- 缺少身高体重时使用 DRIs 推荐值（18–49 岁轻体力活动）。

| key | sex | kcal | protein_g |
|---|---|---|---|
| default_male | 男 | 2150 | 65 |
| default_female | 女 | 1700 | 55 |
| default_unknown | 未知 | 1950 | 60 |

## 活动系数

| key | name | factor |
|---|---|---|
| sedentary | 久坐 | 1.2 |
| light | 轻体力 | 1.375 |
| moderate | 中体力 | 1.55 |
| active | 重体力 | 1.725 |

## 餐次能量分配

| meal | name | share |
|---|---|---|
| breakfast | 早餐 | 0.30 |
| lunch | 午餐 | 0.40 |
| dinner | 晚餐 | 0.30 |

## 每日上限（一般成人）

- 食盐 < 5 g；烹调油 25–30 g；添加糖 < 50 g，最好 < 25 g。
- 脂肪供能 20%–30%；碳水供能 50%–65%（减脂人群可适当降低）。

## 校验阈值（三层校验中的营养校验）

- 每人每餐能量在目标的 80%–125% 之间。
- 每人每餐蛋白质不低于目标的 80%。
