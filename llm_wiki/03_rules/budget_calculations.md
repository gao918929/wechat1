# 预算与价格口径 Budget Calculations

## 两个口径（不可混用）

- **记账** = 实际花了多少钱：以小票**实付金额**为准，是流水账，不可篡改。
- **成本测算** = 规划前预估本周买菜要花多少：用于判断是否超预算。

## 成本测算的价格优先级

1. 用户历史真实成交价（来自小票/价签，最近 90 天中位数）——最真实，优先使用。
2. 无历史 → 地区参考价（本库 `price_min`–`price_max` 的中值），**标注“估算”**。

## 缺失单价的分级补全

| 缺失情况 | 补全方式 |
|---|---|
| 缺单价，有总价和重量 | 单价 = 总价 ÷ 重量，自动计算 |
| 缺单价，有总价和数量 | 用参照重量估算重量 → 反推单价（标注“估算”） |
| 缺单价且缺重量 | 默认参考价，标注“估算”，允许用户修改 |
| 全部明细缺失（手写只有总价） | 记账只记总金额；成本测算用参考价并标注“估算” |

## 预算口径

- 默认**人均预算**（适合宿舍合餐）：总预算 = 人均 × 就餐人数。
- 可一键切换为**总预算**。
- 测算只计入需购买的食材（已扣除库存）；常备调料（`pantry`）不计入。
- 超预算时，预算智能体按同类食材中更便宜的替代品进行替换，并保证不违反任何硬约束。
