# MealAgent LLM Wiki · 知识库索引

本知识库是所有智能体（健康适配 / 库存优先 / 预算约束 / 迭代优化）共享的事实依据，
由结构化 Markdown 组成，既可人工维护，也被后端程序直接解析（表格与 `- key: value` 列表）。

## 目录

| 目录 | 内容 | 程序如何使用 |
|---|---|---|
| `01_ingredients/` | 食材营养（每 100 g 可食部）、保质期类别、参考价格（元/kg）、单个参考重量与尺寸、过敏原与标签 | 营养计算、成本测算、保质期预警、参照物估算、硬约束过滤 |
| `02_dietary_group_models/` | 人群膳食模型参数 + 指导原则 | 计算能量与三大营养素目标、偏好/回避标签、是否触发差异化多菜 |
| `03_rules/` | 冲突优先级、预算口径、保质期、份量与参照物、营养目标 | 校验器阈值、价格补全、保质期阈值、参照物库 |
| `04_dish_templates/` | 菜品模板（每份用量） | 候选菜池；智能体也可在此基础上调整或组合新菜 |

## 解析约定（维护时请保持）

1. 食材表：表头第一列必须是 `name`；多值字段用 `/` 分隔；空值写 `-`。
2. 价格单位统一为 **元/kg**；营养单位：能量 kcal，蛋白质/脂肪/碳水/膳食纤维 g，维生素C/钙/铁/钠 mg。
3. 菜品：`## 菜名` 开头，随后 `- key: value` 列表；`ingredients` 写成 `食材名 克数, 食材名 克数`（**每人份**）。
4. 人群模型：`## Parameters` 小节下的 `- key: value` 为机器参数，其余为给 LLM 的指导原则。
5. 用户小票中的真实成交价会写入价格记忆，**优先于**本库参考价；参考价使用时一律标注“估算”。

## 数据来源（答辩时用于说明可信度）

- 《中国食物成分表》（标准版 第6版，杨月欣 主编，北京大学医学出版社）——食材营养数值的基础来源。
- 《中国居民膳食营养素参考摄入量（2023版）》（中国营养学会）——能量与营养素目标。
- 《中国居民膳食指南（2022）》（中国营养学会）——油盐糖上限、餐次能量分配、人群建议。
- 可扩展来源：USDA FoodData Central（交叉验证；在食材表新增列或新增文件即可接入）。

> 说明：本库数值为依据上述来源整理的**近似值**（四舍五入，不同品种/部位有差异），
> 用于一般性膳食建议，不构成医疗依据。参考价格为城市商超常见区间，需按实际城市校准。
