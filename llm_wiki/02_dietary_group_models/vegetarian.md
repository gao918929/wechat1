# 素食 Vegetarian (Lacto-Ovo)

## Parameters

- id: vegetarian
- name: 素食（蛋奶素）
- kcal_factor: 1.0

- sugar_g_max: 40
- prefer_tags: plant_protein, soy, vegetable, whole_grain, mushroom
- avoid_tags: -
- hard_forbidden: -
- member_avoid: poultry, pork, beef, lamb, organ, processed, fish, shellfish, mollusk
- special_need: false
- triggers_differentiated: true

## Guidance

- 默认蛋奶素：不含畜禽肉与水产，可含蛋、奶；用豆制品、蛋、奶保证蛋白质，注意铁与维生素 B12。
- 与非素食者合餐时启用差异化多菜：荤菜标注“素食者不吃”，同时保证每餐至少一道素食者可吃的蛋白质菜。
